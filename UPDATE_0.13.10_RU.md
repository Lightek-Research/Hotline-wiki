# Обновление документации HOTLINE 0.13.10

Обновлены русская и английская версии всех разделов руководства, новые иллюстрации и поисковый индекс. Сохранены исходные CSS, переключатель темы, мобильное меню, просмотр картинок и механизм поиска.

## Публикация на существующем GitHub Pages

1. Распакуйте архив.
2. Откройте существующий репозиторий Hotline-wiki.
3. Загрузите содержимое папки Hotline-wiki-main в тот же корень / каталог публикации, где сейчас лежит index.html. Не создавайте дополнительную вложенную папку Hotline-wiki-main на сайте.
4. Замените существующие файлы и сделайте commit.
5. Дождитесь завершения публикации GitHub Pages и обновите страницу.

Особенно важно заменить assets/search-data.js и обе картинки: иначе поиск и иллюстрации останутся от старой версии.

Архив содержит готовые файлы сайта. Commit в GitHub и публикация из этой сессии не выполнялись.
