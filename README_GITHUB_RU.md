# HOTLINE Wiki — готовый сайт для GitHub Pages

В этом архиве находится готовый статический сайт на основе предоставленных HTML-экспортов EN/RU. Содержимое страниц сохранено; добавлены собственные стили, меню и функции навигации. Это самостоятельное оформление, а не точная копия оболочки исходного сервиса.

## Публикация

1. Создайте публичный репозиторий GitHub, например hotline-wiki. Для GitHub Pages на бесплатном аккаунте нужен публичный репозиторий. Загружайте только документацию: Lua-скрипты системы здесь не требуются.
2. Распакуйте ZIP и загрузите СОДЕРЖИМОЕ архива в корень репозитория: index.html, assets, en, ru. Не загружайте один ZIP вместо распакованных файлов. Не помещайте все файлы внутрь дополнительной папки.
3. Сохраните изменения коммитом в основную ветку, например main.
4. Откройте Settings → Pages. В Build and deployment выберите Deploy from a branch, затем свою основную ветку и /(root). Сохраните.
5. Дождитесь завершения публикации. GitHub покажет ссылку на сайт в разделе Pages. Если требуется, проверьте статус сборки в Actions.

В комплект включён .nojekyll для публикации готовых файлов без обработки Jekyll. Некоторые файловые менеджеры скрывают его. Если он не загрузился, создайте пустой файл с именем .nojekyll в корне репозитория.

Сайт пока не опубликован: доступа к вашему репозиторию в этой задаче не было.

## Что работает

- Главная страница выбора языка и 20 страниц из экспортов EN/RU.
- Боковое меню, оглавление текущей страницы, предыдущая/следующая страница.
- Переключение языка с сохранением соответствующей страницы.
- Светлая и тёмная темы; предпочтение сохраняется локально в браузере.
- Поиск по тексту на текущем языке, в том числе Ctrl+K.
- Увеличение изображений по нажатию; Esc закрывает просмотр и поиск.
- Компоновка для узкого экрана с раскрывающимся меню.

Исходные тексты из экспортов не переписаны. Дублирующие битые ссылки на картинки удалены; настоящие вложения сохранены. Внутренние .md, HTML и ссылки на прежнее пространство преобразованы в локальные пути. Все 478 внутренних ссылок, файлов и якорей проверены. Светлая/тёмная тема, поиск, просмотр картинки и смена языка проверены в браузере; отдельного визуального теста телефона не проводилось.

## Шрифт и оформление

В экспортах не было CSS и файлов исходного шрифта. Восстановлены стили текста, таблиц, блоков кода и страниц. Используется системный современный шрифт: Segoe UI на Windows, системный шрифт Apple на macOS и доступные аналоги на других устройствах. Поэтому конкретная гарнитура может немного различаться. Подключения к внешнему сервису шрифтов нет.

Главный файл оформления: assets/style.css. В начале файла можно менять цвета и font-family. Для полного совпадения гарнитуры на всех устройствах потребуется отдельно добавить лицензированный файл шрифта с латиницей и кириллицей и подключить его через @font-face. Сам исходный шрифт определить по этим архивам нельзя.

## Обновление текстов

Правьте соответствующий HTML в en или ru. Поиск использует локальную копию текста в assets/search-data.js — при изменении содержания обновите также поисковые данные. Простое редактирование стилей не требует обновления поиска.

Никакой связи с прежним сервисом экспорта нет: новые изменения оттуда автоматически не синхронизируются.

## Просмотр до публикации

Можно открыть index.html из распакованной папки. Все ресурсы локальные. Для проверки именно как сайта можно выполнить в этой папке `python -m http.server 8000` и открыть http://localhost:8000.
