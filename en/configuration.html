HOTLINE / Configuration

Configuration

Open ServerScriptService → Hotline → Config while Play is stopped.

Access and audio

Add or edit these fields inside the existing Config table:

AdminUserIds = {},

AdminUsernames = {
    "YourUsername",
    "SecondUsername",
},

GlobalAudio = true,

Setting

Behavior

AdminUsernames

Allows the specified Roblox usernames. Use the account username without @, not DisplayName. Matching ignores letter case.

AdminUserIds

Allows numeric Roblox UserIds. Leave empty if you want access by username only.

GlobalAudio = true

All players hear the show's music.

GlobalAudio = false

Only the current operator hears the show's music.

The two access lists are additive: matching either grants access. A name list requires maintenance if an account changes its username; a UserId remains tied to the account.

Use Luau booleans true and false in lowercase. Config changes take effect on newly started servers; already running servers keep the values they loaded.

Advanced overrides

Hotline → Scripts → SecuritySettings holds internal request and scheduling limits. Most installations should leave them unchanged.

An explicit SecuritySettings.AdminUserIds or AdminUsernames overrides its corresponding Config list. The default is nil, which uses Config. An explicit SecuritySettings.GlobalAudio overrides Config.GlobalAudio. Leave it nil to manage audio from Config. The previous BroadcastAudienceAudio setting is a fallback only when the new option is absent.

The old AllowStudio and AllowExperienceOwner flags do not grant access under the strict policy. Add the intended operator explicitly.

Music: Audio ID and a Sound in Config

Enter music when creating the show, or later through Show → Music asset ID. Track volume accepts 0–10, with a default of 0.7. Settings also contains a separate 0–100% local volume control.

To link an external Sound, add this field inside the existing return { ... } table in Config:

ShowSoundTriggers = {
    ["Show1"] = "Workspace.Stage.Music.SoundShow1",
    ["show_slot_2"] = "Workspace.SoundShow2",
},

The left-hand key is the exact show name or save slot. The value is a path to a Sound in Workspace. Set the audio asset in that object's SoundId property. A direct instance reference such as workspace.Stage.Music.SoundShow1 is also supported.

Load mode uses this priority:

  1. A valid Workspace Sound from Config: the show follows its playback and time position. Starting it from a game script also starts the lighting show. Toolbar Play, Pause and Stop control this Sound.
  2. If the link is absent or does not resolve to a Workspace Sound, the show's saved Audio ID is used.
  3. If neither source exists, no music is played and the lighting show runs independently.

With external synchronization, speed and volume come from the Sound properties. The show's internal Audio ID does not play at the same time. GlobalAudio controls HOTLINE's built-in soundtrack: true lets all players hear it; false limits it to the operator. An external Workspace Sound keeps its own Roblox audio settings.

Restart the server / Play for Config changes to take effect. The experience must have permission to use the selected audio asset.
