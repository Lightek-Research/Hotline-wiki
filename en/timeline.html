Timeline and Cue List

Timeline

Use the timeline to place cues in time and organize them across tracks.

  • Click a cue to select it.

  • Drag it to change its position.

  • Drag its right edge to change its duration.

  • Use the inspector to edit cue name, start, length, and track, then press Apply.

  • Use Clone to create a copy after the selected cue.

  • Use Delete to remove the selected cue.

Pause playback and finish recording before editing. A cue cannot be shortened past its recorded events.

Click empty timeline space to move the playhead. The working area extends as you scroll; the initial 1 s project length is not a playback deadline.

Zoom, snap, and follow

Zoom changes the horizontal timeline scale. It does not scale the entire GUI.

Snap sets the editing time grid in seconds. For example, 0.1 gives tenth-second steps; 0 disables snapping. Follow keeps the visible area aligned with playback.

Window presets change the editor's layout. For a custom overall GUI scale, edit the authored UIScale in Studio; there is no general scale slider documented in this version.

Cue List

Cue List is a time-ordered list of individual GLights commands, rather than one row per cue. Each row shows its show time, source cue and track, target, command, and arguments.

Rows are marked LAST, NEXT, or PAST according to the playhead. The most recently scheduled command receives the current-row styling. This is schedule information, not feedback confirming the physical state of a fixture. An effect can continue after its command was sent.

Use a row to select its source cue, edit the event, or seek to its time. Follow can move to the page containing the next command. Previous and Next allow manual paging.

Shortcuts

Shortcut

Action

F6

Show or hide HOTLINE.

Tab

Show or hide timeline panels.

Space

Play or pause; finishes active recording.

Ctrl+Z

Undo an edit when editing is available.

Ctrl+Y

Redo an edit when editing is available.

Esc

Close the current dialog.

Most shortcuts do not run while typing in a text field.
