HOTLINE / Recording cues

Recording cues

Open or create a show in Edit, add a cue and select it. Pause playback and finish the current take before switching Timed / Capture. Record cue records into the selected cue; Load mode does not support recording.

Timed and Capture

These determine how commands are recorded, separate from the overwrite policy.

  • Timed: select a cue and press Record cue. The timeline advances and GLights commands retain their timing offsets. Finish with Finish recording, Pause or the Record shortcut.
  • Capture: select a cue, choose Capture and press Record cue. The timeline stays still. The first supported GLights command is recorded at offset 0 and recording finishes automatically. Waiting time is not included in the event offset.

A short green notification confirms a successful recording. The cue's Events count shows how many commands were saved.

Append and Replace

In Show → Recording, choose what a new take does:

  • Append adds events to the existing take.
  • Replace replaces the selected cue's events. Existing commands are cleared only after the first new command arrives. Cancelling an armed Capture before a command arrives preserves the previous take.

The policy is saved with the show and is independent of Timed / Capture. Older shows without a policy use Append.

Saving

After recording, press Pause and save through Save / Load. Apply updates cue fields; it does not save the whole project to storage.
