HOTLINE / Recording cues

Recording cues

HOTLINE records supported commands sent through GLights. It stores commands and their arguments, rather than capturing rendered frames of the lighting effect.

Before recording

  1. Open or create a show.

  2. Add a cue and select it.

  3. Pause playback before changing the recording mode.

  4. Choose Timed or Capture using the recording mode control.

If a compact panel hides the control, expand More. If the panel itself is hidden, use Panels or press Tab in the timeline.

Timed

Timed records a sequence with its original timing.

  1. Select the cue and choose Timed.

  2. Position the playhead where you want recording to start. It cannot start before the selected cue's start.

  3. Press the record button.

  4. Operate your GLights controls. The timeline advances while HOTLINE records event offsets inside the selected cue.

  5. Press Pause or finish recording.

Example: a cue starts at 10 s. Turning lights on at show time 11 s stores an event at cue offset 1 s. During playback, it is scheduled at 11 s.

Timed recording expands the cue and derived show length when needed. There is no fixed recording duration limit.

Capture

Capture waits for one lighting command without advancing the timeline.

  1. Select a cue and choose Capture.

  2. Press the record button. Recording is now armed.

  3. Send one supported GLights command, for example turning beams on.

  4. HOTLINE adds that command at cue offset 0 and finishes recording automatically.

Waiting five seconds before sending the command does not add a five-second delay. The captured command remains at the beginning of the cue.

To cancel while waiting, use finish/cancel recording or Pause. After Capture completes, you can move and resize the cue. Cancel recording before trying to edit an armed cue.

Confirmation and repeat recording

A brief green confirmation appears when a command has been recorded. If no command was received, arming Capture alone is not confirmation of a recording.

Recording into an existing cue appends events. It does not automatically erase the earlier take. Use the Events editor to inspect or remove unwanted commands, or create a fresh cue for another take.

Pause recording before saving the show.
