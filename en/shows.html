Shows, saving, and playback

Create and open

Use New Show on the Shows screen. Set a show name and any optional song information. Open creates an empty show; the record-start option creates the first cue and starts recording using the selected recording mode.

Music is optional. Leave the audio asset field empty for a lighting-only show. A song title is a label, not an audio upload or an asset permission.

For an existing show, use its Edit action. The saved-show list also provides Copy and Delete; deletion requires confirmation. Refresh reloads the list, and Load More retrieves additional entries when available.

Save and load

  1. Pause playback and finish recording.

  2. Open Save / Load.

  3. Enter or check the storage slot.

  4. Press Save and wait for success confirmation.

The slot identifies the saved record; it is separate from the show's display name. A success notification confirms the server accepted the save. Closing or hiding the GUI does not save your draft automatically.

Shows use the experience's DataStore. Keep DataStoreName unchanged if you want to continue using the same saved library. Revision checks can reject an overwrite when the saved version changed elsewhere: refresh and load the latest version before deciding what to keep.

Playback

Use Play to run from the playhead, Pause to hold the current position, and Stop to return to the beginning and reset targeted GLights state.

Seeking resets relevant targets and replays prior commands to reconstruct a lighting state. Long seeks may take time. This is command replay, not a frame-accurate rewind of every effect's internal animation.

Use Show settings to edit project-level information, playback speed, and audio asset fields. The experience must be allowed to play the audio asset. Test music and lighting together before using a show live.

Who hears music?

Config.GlobalAudio = true enables music for spectators as well as the operator. With false, only the current operator hears it. This preference belongs to the installation, not to each saved show.

The operator's local volume setting does not act as a global mixer for every spectator.
