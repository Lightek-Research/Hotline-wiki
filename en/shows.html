HOTLINE / Shows, saving, and playback

Shows, saving, and playback

New Show in Edit opens show creation. Open timeline creates an empty project; Start recording creates the first cue and starts the selected Timed / Capture mode. Set a name, optional Audio ID, song label, speed, track volume 0–10 and optional waveform image. A song label does not upload audio. Copy creates a separate saved copy; Delete removes the show after confirmation. Refresh updates the list.

Edit and Load

Select EDIT in the main menu to create shows or open saved shows for changes. Edit supports changes during playback. Editing is blocked during active recording.

Select LOAD, then the show's Load action. The editor opens with a compact top-center toolbar. A linked Sound arms the show until that Sound starts; without a link, the saved Audio ID plays immediately. With neither source, only the lighting show starts.

Load provides Play, Pause, Stop, Follow and an Edit button, plus view and list navigation. Cue editing, recording, colors and grouping tools are hidden. Edit stops the show clock and restores editing. When leaving external synchronization, the linked Sound is paused.

Save and load

  1. Pause playback and finish recording.

  2. Open Save / Load.

  3. Enter or check the storage slot.

  4. Press Save and wait for success confirmation.

The slot identifies the saved record; it is separate from the show's display name. A success notification confirms the server accepted the save. Closing or hiding the GUI does not save your draft automatically.

Shows use the experience's DataStore. Keep DataStoreName unchanged if you want to continue using the same saved library. Revision checks can reject an overwrite when the saved version changed elsewhere: refresh and load the latest version before deciding what to keep.

Automatic stop at the end of a track

When the internal track ends, show playback stops. Later commands are not executed and the involved fixtures are reset. Pressing Play after the internal track ends restarts it from the beginning.

The linked Sound ending also stops the show. A show without music has no music-based duration limit and is stopped manually with Stop.

Show settings and music

Show opens project settings, including Append / Replace and track volume. Operator local volume is separate, in Settings. Workspace Sound links and source priority are covered in Configuration.
