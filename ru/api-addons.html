API и автоматизация

API позволяет другому серверному Script загрузить сохранённое шоу HOTLINE, запустить музыку, поставить воспроизведение на паузу и получить состояние. Открытый GUI оператора не обязателен. Поддержка API и аддонов появилась в HOTLINE 0.14.0.

Для подключения других систем откройте Установка и использование аддонов. Чтобы написать свою интеграцию — Создание аддонов.

Первый запуск за несколько минут

  1. Установите HOTLINE в ServerScriptService и настройте Config. Рабочий путь модуля: ServerScriptService → Hotline → Scripts → Api.
  2. В режиме Edit создайте небольшое шоу, добавьте команды в первые секунды и сохраните под уникальным именем API Test.
  3. Создайте обычный Script в ServerScriptService. Используйте серверный RunContext, не LocalScript.
  4. Вставьте код ниже и запустите Play.
local SSS = game:GetService("ServerScriptService")
local Hotline = SSS:WaitForChild("Hotline", 10)
assert(Hotline, "Hotline folder not found")
local Api = require(Hotline:WaitForChild("Scripts"):WaitForChild("Api"))
assert(Api.WaitForReady(20), "HOTLINE is not ready")

local ok, result = Api.PlayShow("API Test", {
    UseConfiguredSound = false,
    Duration = 10,
})
if not ok then
    warn("HOTLINE: " .. tostring(result))
end

Шоу должно запуститься, а через 10 секунд времени шоу — остановиться. Duration в этом примере задан специально для проверки. При другой скорости шоу меняется реальное время до остановки. Если GUI открыт, оператор получит это шоу в Load.

Этот пример выполняется при каждом запуске теста. После проверки отключите тестовый Script, чтобы шоу не стартовало автоматически.

Запуск теста из Command Bar

Удобно хранить тестовый код в выключенном обычном Script HotlineTest внутри ServerStorage. Сам Script в ServerStorage не выполняется. Во время Play переключите Studio на Server и запустите его копию:

local test = game.ServerStorage.HotlineTest:Clone()
test.Enabled = false
test.Parent = game.ServerScriptService
test.Enabled = true

Так команды API выполняются из серверного Script. Не вставляйте весь тестовый код API напрямую в Command Bar: используйте её для запуска подготовленного Script, как выше.

В клиентском Explorer содержимое ServerStorage и ServerScriptService недоступно. Это не означает, что скрипты удалились. Если вы видите NetworkClient и пустые серверные папки, переключитесь на Server.

Как выбрать шоу

PlayShow работает с уже сохранённым световым шоу, а не с произвольным audio ID. Можно передать имя или ID слота:

local ok, result = Api.PlayShow("Opening")
-- Или точный ID сохранения:
local okBySlot, resultBySlot = Api.PlayShow({Slot = "show_your_slot"})

Выполняйте только нужный вариант: каждый PlayShow запрашивает загрузку и запуск. Имя должно совпадать точно и быть уникальным. Для частых запусков лучше ID слота: он не требует поиска по именам всех сохранений. Одинаковые имена вызывают ошибку. Строка, совпавшая с существующим ID слота, выбирает этот слот.

Узнать ID можно через список сохранений. Этот пример использует Api, подключённый как в первом блоке:

local page, err = Api.ListShows(true)
while page do
    for _, show in ipairs(page.shows) do
        print(show.slot, show.name)
    end
    if not page.more then break end
    page, err = Api.ListShows(false)
end
if err then warn(err) end

У API свой курсор страниц: он не перелистывает список в GUI. Поиск по имени ограничен 200 страницами по 50 ключей. Во время записи загрузка другого шоу запрещена. Параллельные операции отклоняются, а не копятся в очереди. Не вызывайте PlayShow каждый кадр.

Play, Pause, Stop и ожидание

Все примеры ниже предполагают уже подключённый Api. Вызывайте нужную команду из своего серверного события, а не все подряд.

ВызовЧто происходит
Api.PlayShow("Opening")Загружает сохранённое шоу и запускает его.
Api.ArmShow("Opening")Загружает шоу в Load без немедленного исполнения сохранённых команд.
Api.Play()Запускает или продолжает текущее шоу.
Api.Pause()Ставит текущее воспроизведение на паузу.
Api.Stop()Останавливает и сбрасывает позицию.
Api.GetState()Возвращает состояние текущего шоу.
Api.GetAddons()Возвращает состояния аддонов.

ArmShow удобно использовать вместе с привязанным Workspace Sound: HOTLINE ждёт, когда тот начнёт играть. Если Sound уже играет, синхронизация начнётся на следующем кадре. Чтобы ждать будущий запуск, Sound должен быть остановлен. Без привязанного Sound после ArmShow нужен Api.Play().

Музыка и параметры запуска

local ok, result = Api.PlayShow({Slot = "show_your_slot"}, {
    RequireIdle = true,
    UseConfiguredSound = true,
    Duration = 52,
})
if not ok then warn(result) end
ПараметрЗначение
RequireIdleПри true отказывается от запуска, если шоу уже играет. По умолчанию false.
UseConfiguredSoundПо умолчанию true: использует валидный Workspace Sound из Config.ShowSoundTriggers. При false выбирает сохранённую музыку шоу.
DurationНеобязательная положительная длительность для внутреннего времени шоу. Подходит и для шоу без музыки. Для привязанного Workspace Sound не используется.

Источники музыки: привязанный Sound по слоту или имени шоу → audio ID в сохранённом шоу → тишина. Настройка ShowSoundTriggers и GlobalAudio.

PlayShow сам запускает/продолжает привязанный Sound. ArmShow только подготавливает синхронизацию. Встроенная музыка без оператора доступна присутствующим игрокам при GlobalAudio=true. При false сохраняется личное аудио оператора. У Workspace Sound своя громкость.

Если Duration не задан, сервер пытается получить длину внутреннего трека. Когда длину определить не удалось, для надёжного автостопа задайте Duration. У шоу без музыки и без Duration нет музыкального дедлайна остановки.

Результаты, состояние и события

PlayShow, ArmShow, Play, Pause и Stop возвращают пару ok, resultOrError. Всегда проверяйте ok. GetState, GetAddons и ListShows возвращают данные либо nil, error.

local state, err = Api.GetState()
if state then
    print(state.name, state.slot, state.position, state.playing)
else
    warn(err)
end

В состоянии также есть recording, recordMode, readOnly, external, automated, speed, soundId и другие поля транспорта. WaitForReady(timeout) ждёт готовности серверного API: по умолчанию 10 секунд, допустимо от 0 до 60. Готовность всех аддонов проверяется отдельно.

Api.Events.ShowLoaded:Connect(function(state)
    print("Loaded:", state.name)
end)
Api.Events.PlaybackStarted:Connect(function(state)
    print("Started:", state.slot)
end)
Api.Events.PlaybackStopped:Connect(function(event)
    print("Stopped:", event.reason, event.state.position)
end)
Api.Events.Error:Connect(function(event)
    warn(event.operation, event.error)
end)
СигналДанные
ReadyГотовность API; если подключились позднее, используйте WaitForReady.
ShowLoaded, PlaybackStarted, StateChangedСостояние шоу. StateChanged сообщает переходы состояния/режима, а не каждый тик позиции.
PlaybackPaused, PlaybackStoppedТаблица с reason и state.
ErrorТаблица с operation и error.
AddonsChangedТаблица состояний аддонов.

Есть команды через BindableEvent: Api.Signals.PlayShow, ArmShow, Play, Pause, Stop. Например:

Api.Signals.PlayShow:Fire("Opening")

У сигналов нет возвращаемого результата. Ошибки смотрите в Events.Error и Output. Чтобы получить ok напрямую, используйте обычный метод.

Доступ и частые ошибки

API доступен доверенному серверному коду. GUI whitelist остаётся на месте. Если делаете собственную кнопку игрока или RemoteEvent, проверяйте права на сервере перед вызовом API. Не передавайте клиенту право запускать произвольные шоу без проверки.

СимптомЧто проверить
Hotline is not a valid member и пометка ClientЗапуск на клиенте. Используйте обычный серверный Script и серверный контекст Studio.
Infinite yield на HotlineИмя и расположение папки; клиент не видит её содержимое. В примере ожидание ограничено 10 секундами.
HOTLINE is not readyОсновной Hotline.Scripts.Server должен работать. Смотрите первые ошибки после старта Play, наличие GLights и Config. Проверяйте из обычного серверного Script.
Saved show not foundШоу должно быть сохранено в том же плейсе/хранилище. Проверьте точное имя или Slot.
Несколько шоу с одним именемИспользуйте Slot.
Required addon unavailableОткройте GetAddons и диагностику аддонов.
Музыку не слышно или нет автостопаПроверьте источник, доступность audio asset, GlobalAudio и Duration.
