Настройки

При остановленном Play откройте ServerScriptService → GLightTimeline → Config.

Доступ и музыка

Добавьте или измените эти поля внутри существующей таблицы Config:

AdminUserIds = {},

AdminUsernames = {
    "YourUsername",
    "SecondUsername",
},

GlobalAudio = true,

Настройка

Поведение

AdminUsernames

Разрешает доступ указанным Roblox Username. Пишите без @; DisplayName не подходит. Регистр букв не важен.

AdminUserIds

Разрешает доступ по числовым Roblox UserId. Оставьте пустым для доступа только по никам.

GlobalAudio = true

Музыку шоу слышат все игроки.

GlobalAudio = false

Музыку слышит только текущий оператор.

Два списка дополняют друг друга: достаточно совпадения в любом из них. При смене Username список имён нужно обновить; UserId остаётся привязанным к аккаунту.

В Luau значения true и false пишутся маленькими буквами. Изменения Config применяются на новых запусках сервера. Уже запущенные серверы используют загруженные ранее значения.

Служебные переопределения

GLightTimeline → Scripts → SecuritySettings содержит ограничения запросов и планировщика. В обычной установке их лучше оставить без изменений.

Явный список SecuritySettings.AdminUserIds или AdminUsernames заменяет соответствующий список Config. По умолчанию стоит nil, то есть используется Config. Явное значение SecuritySettings.GlobalAudio имеет приоритет над Config.GlobalAudio. Оставьте nil, чтобы менять музыку через основной Config. Старый параметр BroadcastAudienceAudio используется только как запасной, если новая настройка нигде не задана.

Старые флаги AllowStudio и AllowExperienceOwner не дают доступ при строгой политике. Нужного оператора добавляйте явно.
