HOTLINE / Настройки

Настройки

При остановленном Play откройте ServerScriptService → Hotline → Config.

Доступ и музыка

Добавьте или измените эти поля внутри существующей таблицы Config:

AdminUserIds = {},

AdminUsernames = {
    "YourUsername",
    "SecondUsername",
},

GlobalAudio = true,

Настройка

Поведение

AdminUsernames

Разрешает доступ указанным Roblox Username. Пишите без @; DisplayName не подходит. Регистр букв не важен.

AdminUserIds

Разрешает доступ по числовым Roblox UserId. Оставьте пустым для доступа только по никам.

GlobalAudio = true

Музыку шоу слышат все игроки.

GlobalAudio = false

Музыку слышит только текущий оператор.

Два списка дополняют друг друга: достаточно совпадения в любом из них. При смене Username список имён нужно обновить; UserId остаётся привязанным к аккаунту.

В Luau значения true и false пишутся маленькими буквами. Изменения Config применяются на новых запусках сервера. Уже запущенные серверы используют загруженные ранее значения.

Служебные переопределения

Hotline → Scripts → SecuritySettings содержит ограничения запросов и планировщика. В обычной установке их лучше оставить без изменений.

Явный список SecuritySettings.AdminUserIds или AdminUsernames заменяет соответствующий список Config. По умолчанию стоит nil, то есть используется Config. Явное значение SecuritySettings.GlobalAudio имеет приоритет над Config.GlobalAudio. Оставьте nil, чтобы менять музыку через основной Config. Старый параметр BroadcastAudienceAudio используется только как запасной, если новая настройка нигде не задана.

Старые флаги AllowStudio и AllowExperienceOwner не дают доступ при строгой политике. Нужного оператора добавляйте явно.

Музыка: Audio ID и Sound из Config

Музыку можно указать при создании шоу или позднее через Show → Music asset ID. Громкость трека задаётся в диапазоне 0–10, по умолчанию 0.7. В Settings отдельно задаётся локальная громкость 0–100%; это разные настройки.

Для внешней синхронизации добавьте поле в существующую таблицу return { ... } файла Config:

ShowSoundTriggers = {
    ["Show1"] = "Workspace.Stage.Music.SoundShow1",
    ["show_slot_2"] = "Workspace.SoundShow2",
},

Слева — точное имя шоу или слот сохранения. Справа — путь к объекту Sound в Workspace. Сам Audio ID указывается в свойстве SoundId этого объекта. Вместо строки пути допустима прямая ссылка на объект, например workspace.Stage.Music.SoundShow1.

Приоритет в Load:

  1. Корректный Workspace Sound из Config — шоу следует его времени и воспроизведению. Начальный запуск внешним игровым скриптом также запускает световое шоу. Play, Pause и Stop на панели управляют этим Sound.
  2. Если привязки нет или она не разрешается в Workspace Sound, используется Audio ID, сохранённый в шоу.
  3. Если нет обоих источников, музыка не включается, а световое шоу работает самостоятельно.

При внешней синхронизации скорость и громкость определяются свойствами Sound. Встроенный Audio ID шоу одновременно не воспроизводится. GlobalAudio управляет встроенным аудио HOTLINE: true — слышат все игроки, false — только оператор. Внешний Workspace Sound сохраняет собственные настройки Roblox.

Изменения Config вступают в силу после перезапуска сервера / Play. Игра должна иметь право на использование выбранного аудио.
