Начало работы

Что понадобится

  • Roblox Studio и права на изменение игры.

  • Совместимая установка GLights. HOTLINE вызывает её серверный API и не заменяет GLights.

  • Полная обновлённая модель HOTLINE вместе с GUI-шаблоном.

  • Разрешение на использование выбранных аудиоассетов в этой игре.

Установка готовой модели

  1. Сохраните резервную копию place и остановите Play.

  2. Поместите обновлённую модель Hotline в ServerScriptService. Устанавливайте только одну копию.

  3. Оставьте Config непосредственно внутри Hotline. Рабочие модули и GUI-шаблон должны находиться в Hotline → Scripts.

  4. Настройте доступ в существующем Config. Например:

AdminUserIds = {},
AdminUsernames = {"YourUsername"},
GlobalAudio = true,

Это поля внутри существующей таблицы return { ... }. Вместо YourUsername укажите настоящий Roblox Username. Не заменяйте этим коротким примером весь Config.

  1. Проверьте GLightsName. По умолчанию это GLights — имя модели GLights в Workspace. Интеграция ожидает внутри неё путь Scripts → Core → Main.

  2. Запустите тест с явно допущенным аккаунтом. Владелец игры и режим Studio не обходят whitelist.

Сервер копирует GUI редактора только разрешённым игрокам. Остальные получают небольшой скрипт воспроизведения музыки. Редактором одновременно владеет один оператор.

Первая проверка

Откройте новое шоу, добавьте кью, выберите Timed или Capture и запишите простую команду GLights. Остановите запись, вернитесь к началу и нажмите Play. Проверьте реакцию нужных приборов. Затем проверьте сохранение и загрузку шоу.

Для проверки сохранений используйте опубликованную тестовую игру с доступом к DataStore. Если включаете Studio API access, делайте это в отдельной тестовой игре, чтобы не изменять рабочие сохранения из Studio.

Обновлённая версия

Это руководство описывает HOTLINE 0.13.10. В комплектной модели Config находится в корне Hotline, а рабочие скрипты и GUI — в Scripts. Выберите Edit для создания и изменения, Load — для воспроизведения. При обновлении остановите Play и сохраните резервную копию старой модели; устанавливайте одну рабочую копию. Готовая модель не требует отдельных патчей или команды require.
